# Зроблено пiд aarch64

У розглянутих програмах використовується кілька ключових системних викликів ядра Linux. Давайте детально розберемо кожен із них: які аргументи вони приймають, що повертають при успішному виконанні та у разі виникнення помилки.

---

### 1. `open` / `openat` (відкриття або створення файлу)

Системний виклик `open` (або його сучасніший аналог `openat`) призначений для відкриття файлу та отримання файлового дескриптора.

* **Аргументи:**
1. `const char *pathname` — шлях до файлу (відносний або абсолютний). У разі `openat` першим аргументом зазвичай передається дескриптор каталогу (наприклад, `AT_FDCWD` для поточної робочої директорії).
2. `int flags` — режим доступу та прапорці (наприклад, `O_RDONLY` — тільки читання, `O_WRONLY` — тільки запис). Прапорці можна об'єднувати бітовою операцією «АБО» (`|`):
* `O_CREAT` — створити файл, якщо він не існує.
* `O_TRUNC` — якщо файл існує і відкривається для запису, його довжина усікається (зрізається) до 0 (файл повністю очищується).


3. `mode_t mode` — права доступу (наприклад, `0644`), які застосовуються **тільки** якщо створюється новий файл (`O_CREAT`).


* **У разі успіху:** Повертає невід'ємне ціле число — **файловий дескриптор** (`fd`), який використовується для подальших операцій (наприклад, `3`).
* **У разі помилки:** Повертає `-1`, а глобальна змінна `errno` встановлюється у код помилки (наприклад, `ENOENT` — файл не знайдено, або `EACCES` — бракує прав доступу).

---

### 2. `write` (запис даних у файл)

Записує байти з буфера у файл, пов'язаний із файловим дескриптором.

* **Аргументи:**
1. `int fd` — файловий дескриптор відкритий для запису.
2. `const void *buf` — вказівник на буфер із даними, які потрібно записати.
3. `size_t count` — кількість байтів, яку необхідно записати.


* **У разі успіху:** Повертає **кількість реально записаних байтів** (у разі успіху зазвичай дорівнює `count`).
* **У разі помилки:** Повертає `-1`, а `errno` отримує відповідне значення (наприклад, `ENOSPC` — брак місця на диску).

---

### 3. `read` (читання даних із файлу)

Зчитує байти з файлу у буфер.

* **Аргументи:**
1. `int fd` — файловий дескриптор відкритий для читання.
2. `void *buf` — вказівник на буфер у пам'яті, куди будуть записані прочитані дані.
3. `size_t count` — максимальна кількість байтів для читання.


* **У разі успіху:** Повертає **кількість фактично прочитаних байтів** (може бути меншою за `count`, якщо досягнуто кінця файлу — `EOF`, тоді повертається `0`).
* **У разі помилки:** Повертає `-1`, а `errno` встановлюється у код помилки.

---

### 4. `lseek` (зміщення покажчика файлу)

Змінює поточну позицію покажчика (курсора) у файловому дескриптора.

> *Важливо:* `lseek` **не змінює жодних даних у самому файлі** і не виконує операцій читання/запису. Він лише переміщує внутрішній «вказівник», який визначає, звідки почнеться наступне читання чи запис.

* **Аргументи:**
1. `int fd` — файловий дескриптор.
2. `off_t offset` — зміщення (у байтах), на яке потрібно пересунути покажчик.
3. `int whence` — точка відліку для зміщення:
* `SEEK_SET` — зміщення рахується від початку файлу.
* `SEEK_CUR` — від поточної позиції покажчика.
* `SEEK_END` — від кінця файлу.




* **У разі успіху:** Повертає нове значення зміщення покажчика від початку файлу (у байтах).
* **У разі помилки:** Повертає `(off_t)-1`, а `errno` отримує значення (наприклад, `EINVAL` для некоректного значення `whence`).

---

### 5. `close` (закриття файлового дескриптора)

Звільняє файловий дескриптор, після чого він більше не пов'язаний із файлом, а системні ресурси повертаються операційній системі.

* **Аргументи:**
1. `int fd` — файловий дескриптор, який потрібно закрити.


* **У разі успіху:** Повертає `0`.
* **У разі помилки:** Повертає `-1`, а `errno` встановлюється у код помилки (наприклад, `EBADF` — передано недійсний дескриптор).
